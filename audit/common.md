## Additional consolidation

- A08: `domain/common/catalog-input.ts` owns player/team create and edit schemas; UI forms, HTTP routes, and engine commands use the same field contract. Removed duplicate field validators and retained world-level catalog invariants in the engine. Nullable formation clears an edit; creation omits an empty formation. Player positions enforce uniqueness and at least one natural position. The engine also rejects nonfinite or out-of-range input from direct callers.
- A09: `observedPlayerFacts` supplies shared knowledge, observation, age, position, overall, potential range, and attributes to lookup and squad. Scouting prose accepts that same projection. Formatting remains renderer-owned; hidden simulation values are not substituted for observed facts.
- Additional negotiated test ownership: AI-market seasonal count/fee bands were removed; market-only stepping preserves money, ownership, squad and deterministic transaction checks without simulating unrelated matches. Departures retains all severance/loan boundaries and merges a duplicate ledger-label case into the existing settlement test. Manager-market sequential stories are single integration cases rather than order-dependent tests; contract boundary cases clone a base fixture. Renewal tests follow explicit review_board approval/rejection rather than the removed automatic reputation gate. Duplicate declined-interview input and stale automatic-reputation titles were removed.
- The skills talk tests now submit bounded continuous reactions, explicitly request issue resolution, and retain cap, scope, atomicity, promise and ledger checks. Automatic leadership/outcome ladder tests were removed with that policy.
- Corrected the `growthLog` comment: the log is capped at 4,000 entries, not permanent.

## Preserved structure and limits

Keep shared player/team schemas and deterministic rules, ledger conservation, event logs, save-version rejection, atomic transaction boundaries, content-addressed shards and repair, role/position/fitness/adaptation/form facts, and legitimate harness-only pure helpers. Test helpers already cache original worlds and clone each call; catalog tests intentionally rebuild. No guessed LOC savings or per-call world-generation cost claims are made. League/cup rules, colours, and derbies still read catalog data; the saved identity fix does not claim every global catalog input has been snapshotted.

Persistence load reparses disk and has no mutable GameState cache. The parent fixed the separate web command dedup marker written before save. Postcommit sidecar/prune failures remain nonfatal. Lock safety prioritizes exclusion: a corrupt or remote-owner attempt is not stolen on a clock timeout; timeout only withdraws the current attempt.

추가 orphan 정리: `common/players/hierarchy.ts`의 `dressingRoomFactor`, 그 함수만 부르던 `dressingRoomVoice`, 세 배율 상수를 제거했다. 전체 사용처 검색에서 런타임 소비자가 없었으며 wildcard export도 함께 사라진다. `leaderWeightOf`(이탈 사기)와 `leaderSettlingRelief`(적응)는 실제 소비자가 있어 유지했다. 옛 hierarchy 테스트 파일은 이미 없고 skills의 구식 팀토크 배율 테스트도 삭제되어 있다.

추가 정리 검증: departures·settling focused tests 2개 파일 54개 테스트 통과. 해당 source ESLint/Prettier 통과.

시즌 도우미 정리: `playFullSeason`의 감독 경기를 `settleMatchdayQuick`으로 결산한다. 실제 라이브 결산 테스트는 유지한다. `keepSeat`는 만료 90일 이내 미판단 계약에 `reviewBoard(renewal: true)`를 실행하고 수락한다. helpers의 중복 날짜 차이 공식은 도메인 `diffDays`로 통일했다. season/world의 기존 시즌 완료·원장·전환 2건과 91일/90일/반복 호출 재계약 경계 1건이 통과했다(2개 파일, 대상 3건, 전체 실행 6.08초). 변경 소스 ESLint와 Prettier도 통과했다.
