# 경기 결산 실호출 확인

`packages/agents/harness/settlement-eval.ts`는 시드 42의 메모리 게임에서 공간 경기를
종료까지 실행하고 실제 출전 선수·사건·평점 앵커로 Jev 결산을 확인한다. 사용자 저장
게임이나 기록 입력 비교가 아니다. `.log`·`.data`·trace·disk journal을 열지 않는다.

```bash
pnpm exec tsx packages/agents/harness/settlement-eval.ts --out /tmp/settlement-eval-example --live
```

`--live`를 생략하면 외부 호출 없이 경기와 요청만 조립한다. 결과는 새 `/tmp` 경로에만
쓴다. 실호출은 `TYPESAFE_API_KEY`와 `evaluators.finalize-match` 설정을 사용한다.

2026-09-28 KST(2026-09-27 16:18 UTC), 게임 버전 `12.0.0`, `jev-1.13.0`의
직접 TypeSafe API로 한 번 측정했다. 40개 사건이 있는 아스날 3:2 프라이부르크 경기의
출전 11명·33질문을 요청 1회/시도 1회로 처리했다.

|     지연 | 입력/출력 토큰 | 정가 환산 비용 | 평점 변경 | 적응 변경 | 능력치 변경 |
| -------: | -------------- | -------------: | --------: | --------: | ----------: |
| 315.07ms | 11,901 / 3,988 |   $0.000499842 |       8명 |       4명 |         0명 |

지연은 타입 평가와 `settleMatchRating` 적용을 포함하며, 경기 생성·진행·GM·사후 검사는
제외한다. 비용은 설정의 입력 $0.042/백만 토큰·출력 무료로 계산한다.
[공식 API·가격 근거](models.md)를 따른다.

전원 반영·대상 제한·평점 앵커 한도·능력치 장부 대응·중복 반영 방지를 통과했다.

`38c34bd37b39985ca7532da28b78a5eb9bfcb976ee0d7f98f0a17bd55c0b93cb`.

생성형과 쌍 비교하지 않았으며 속도·비용 개선이나 기능 동등성을 주장하지 않는다.
