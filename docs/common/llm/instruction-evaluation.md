# 직접 지시 평가 — 합성 입력과 전체 턴

`packages/agents/harness/instructions-eval.ts`는 현재 평시 명령 목록과 실제 상태 문맥으로
직접 지시를 평가하는 수동 하네스다. 기본 실행은 오프라인이며 `--live`가 있어야
TypeSafe를 호출한다. `--turn`은 별도의 새 메모리 게임에서 양성·음성 입력을 실제
`runGmTurn`까지 실행한다. 세이브를 만들거나 사용자 로그·데이터를 읽고 쓰지 않는다.

합성 예제는 명시적 전술 축, 상대적 한 칸 변경, 실행하지 말라는 가정, 정확한 한국어
금액, 시드 선수 지정 다섯 개다. 전체 명령 카탈로그를 제시하되 예제 기대 명령과
일치하는지를 보는 것이며 대표 사용자 입력의 정확도나 기존 경로 대비 개선을 뜻하지
않는다. 컴파일러 평가는 명령 인자만 비교하고 전체 턴 평가는 실제 적용된 전술과 호출
기록을 확인한다. 서사 품질의 블라인드 평가는 별도다.

## 실행

```bash
pnpm exec tsx packages/agents/harness/instructions-eval.ts \
  --out /tmp/instructions-offline

pnpm exec tsx packages/agents/harness/instructions-eval.ts \
  --live --turn --out /tmp/instructions-live \
  --gm-input-usd-per-million 0.75 \
  --gm-output-usd-per-million 3.75 \
  --gm-cached-input-usd-per-million 0.075
```

모델은 `config/llm.yml`만 읽는다. 앱 `.env.local`은 `--live`에서만 로드하고 키는
기록하지 않는다. 출력은 새 디렉터리의 `report.json`·`summary.md`이며 `.log`·`.data`
안이나 그곳으로 향하는 심볼릭 링크 아래에는 쓸 수 없다. 기존 디렉터리도 재사용하지
않는다. 차단·실패·기대 불일치는 종료 코드 1과 보고서에 남는다.

Jev 단가는 설정의 확인된 입력 단가와 무료 출력을 사용한다. GM 가격은 실행자가
확인해서 인자로 준다. 위 예시는 2026-09-27 확인한
[Google 일반 유료 가격](https://ai.google.dev/gemini-api/docs/pricing#gemini-3.8-flash)의
현재 GM 모델 가격이며 2026-12-31까지의 가격이다. 실제 계정 청구액은 아니다.
다른 에이전트가 함께 불리거나 미보고 사용량·가격이 있으면 전체 비용은 미확정이다.

컴파일러 보고서는 각 평가 단계와 내부 재시도의 보고된 토큰을 실패까지 합산한다.
전체 턴은 `withGameUsage`의 에이전트별 장부를 읽으며 실패한 호출의 보고된 토큰도
남긴다. 이 장부의 호출 수는 HTTP 재시도 횟수가 아니며, 제공자가 보고하지 않은
실패 토큰은 알 수 없다. 실행 시간이 빠르거나 다섯 예제가 맞았다는 사실만으로
정확도·비용·전체 턴 지연의 개선을 주장하지 않는다.

양성 턴의 GM은 입력 12,762·출력 298토큰, 음성 턴의 GM은 입력 12,673·출력 300토큰을

모든 캐시 쓰기는 0이었다. 위 비용은 이 캐시 읽기에 별도 단가를 적용한다.
평가 사용량과 합친 금액은 TypeSafe 입력 $0.042/백만 토큰과 앞서 확인한 Google 정가를
사용한다. 캐시 여부가 다른 두 턴의 비용 차이를 지시 경로의 개선으로 해석하지 않는다.
실제 결제액·생략된 과금 정보까지 측정했다고 주장하지 않는다.

로컬 원본 결과는 `/tmp/story-fm-867-instructions-final-20260928/report.json`과
같은 디렉터리의 `summary.md`다. 디렉터리 이름과 별개로 실제 실행 시각은 위 UTC 기록을
따른다. 보고서의 차단 사유·실패·기대 불일치는 없었다.
다른 입력·협상·경기 범위의 정확도, 블라인드 서사 품질, 동일 입력의 기존 생성형 경로와
비교한 전체 턴 지연·비용은 이 표로 알 수 없다. **다섯 예제와 두 턴은 운영 개선의
채택 근거가 아니라 실제 연결과 제한된 기대 동작의 확인**이다.
