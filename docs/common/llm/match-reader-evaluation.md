# 경기 판독 비교 하네스

`packages/agents/harness/match-reader-eval.ts`는 저장된 판독 입력을 읽어 두 평가
경로를 비교하는 수동 하네스다. 서비스의 경기 지시는 [타입 판독 경로](agents.md)를
사용한다. 하네스의 생성형 기준 경로와 산문 뒤 Jev 강도 평가 경로는 운영 호출이 아니다.

## 비교 범위

같은 기록 입력에서 조건·대상·동작·강도와 명령을 비교한다. 감독 발화가 없는 입력은
명령 품질 집계에서 제외한다. 과거 호출은 입력 자료이며 정답이나 현재 성능 기준이 아니다.

## 다시 실행하기

```bash
pnpm exec tsx packages/agents/harness/match-reader-eval.ts \
  --logs /Users/dhoonjang/local/story-fm/apps/web/.log \
  --out /tmp/reader-eval-offline
```

기본은 네트워크 없는 인벤토리다. 실제 비교는 다음처럼 실행한다. 가격 인자는 실행
시점의 공식 가격을 다시 확인한다. 실행 보고서에 기록된 코드와 설정을 기준으로 비교한다.

```bash
pnpm exec tsx packages/agents/harness/match-reader-eval.ts \
  --logs /Users/dhoonjang/local/story-fm/apps/web/.log \
  --out /tmp/reader-eval-live \
  --live --baseline-agent history-compactor \
  --input-usd-per-million <현재-선택한-모델의-입력-단가> \
  --output-usd-per-million <현재-선택한-모델의-출력-단가> \
  --cached-input-usd-per-million <현재-선택한-모델의-캐시-단가>
```

`--out`은 새 디렉터리를 사용한다. 원본 로그 안이나 그곳으로 향하는 심볼릭 링크
아래로는 출력할 수 없고 기존 결과 파일도 덮어쓰지 않는다. 결과는 `report.json`과
`summary.md`다. 보고서는 게임 버전과
산문 시도별 시스템 프롬프트·스키마 SHA-256을 남기며 원문 입력을 복사하지 않는다.
원문 경로와 쌍별 산출·확률은 로컬 보고서에서만 연결한다.

실호출은 `TYPESAFE_API_KEY`와 현재 판독기 제공자의 키가 필요하고 앱의 `.env.local`은
실호출 때만 읽는다. `--limit N`으로 입력 수를 제한할 수 있다. 모델은 `config/llm.yml`만
읽는다. `--baseline-agent`는 해당 역할의 모델·시한·토큰 한도만 빌리며, 역할의 실제
프롬프트나 스킬을 실행하지 않는다. 비교 프롬프트는 `harness/reader-baseline.ts`에
고정되어 있다. 보고서는 선택한 설정도 남기므로 과거의 실행 한도와 구분할 수 있다.
가격이 없거나 실패 요청의 토큰이 보고되지 않으면 비용은 미확정이다. 현재
가격을 과거 기록에 소급하지 않는다.

먼저 실행할 경로를 번갈아 캐시 순서 영향을 줄인다. 실패도 지연·성공률·알려진 토큰
합에 남기며, 실패한 쌍이나 실호출 차단 사유가 있으면 종료 코드는 1이다. 에러 종류와
어댑터가 만든 고정 진단 문구만 보고하고 제공자 본문·키는 출력하지 않는다. SDK 내부
재시도에서 보고하지 않은 사용량까지 안다고 가정하지 않는다.

## 결과 해석

시트 구조는 포인트 문장을 공백 정규화한 뒤 대상·모양·부호·동작이 같은 줄끼리
일대일 대응한다. 미대응 줄 수·Jaccard와 대응 줄의 강도 MAE를 함께 읽는다.
표현이 다른 동의어도 미대응이 될 수 있어 자동 점수만으로 품질을 판정하지 않는다.
명령 비교는 객체 키 순서를 정규화하되 명령 배열의 순서는 보존한다.

실행 순서를 번갈아 캐시 영향을 줄이고 실패도 지연·사용량·성공률에 포함한다.
비교 보고서의 소스 지문·모델 설정·표본 수·미보고 사용량을 함께 확인한다.
사람이 사실 근거, 이득과 대가, 감독 지시 충실도와 선수 상태를 가리는 오류를
검토해야 한다. 측정 범위에 없는 매치 GM 중계나 브라우저 재개 지연으로 일반화하지 않는다.
