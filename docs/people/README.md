# people — 인물

세계의 사람들을 소유한다 — 인물 카탈로그와 인물 사전, 로어북(팀·선수·인물이 함께 쓰는 한 권)의
저장·검색·편집, 스태프 고용, 메일함과 보고 메일, 언론과 기자회견, 수석코치의 사실, 감독의
고용·계약·커리어 기록과 업적.

엔진 도메인의 맨 위다 — 인물은 아래의 모든 사실(선수·경기·순위·재정)을 읽어 말과 기사로 옮긴다.
