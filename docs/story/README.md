# 일상과 서사

메인 GM이 감독의 말과 인물의 맥락을 읽어 훈련·면담·회견을 진행한다. 인물 기억과 관계는 다음 장면에 이어지고, 보드의 기대와 평가는 자유로운 문장으로 남는다.

소유하는 책임: 훈련 계획·성장, 인물·심경·기억·관계, 회견·사회적 반응, 보드와 경력.

선수의 기본 정보는 common을 읽고, 계약·금액·선수 약속의 변경은 common 명령이 기록한다. 경기 승패는 match가 소유한다.

코드는 `packages/domain/src/story`, `packages/engine/src/story`,
`packages/agents/src/story`, `apps/web/domains/story`에서 찾는다.
여러 경험을 연결하는 실행 흐름은 engine·agents의 `app/workflows/story`에 있다.

[전체 문서 지도](../README.md) · [아키텍처](../architecture.md)

다가옴은 GM이 현재 선수·계약·경기·약속의 사실을 보고 여는 장면이다. 날짜마다 쌓는
압력이나 정해진 유출 계단은 없다. 코어는 실제 화자·대상, 한 번에 열린 자리,
날짜·응답 기한과 검증된 반응을 관리한다. 기분 사실은 GM에게 전부 제공하고 화면에서만
요약한다. 코치 원형은 사실 접근 권한을 가르지 않는다. 불만과 시작 사건의 해소는
대화의 결과와 대상에 근거한 명시적 판정으로 기록한다.
