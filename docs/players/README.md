# players — 선수

선수 한 사람에 관한 사실과 규칙을 소유한다 — 선수 카탈로그와 시드에서 16축 능력치를 세우는 규칙,
선수 원형(처음 로어북), 포지션·역할, 폼·체력·부상·누적 피로, 관측(안개)과 성장 가능성, 전술
적응도, 등번호와 주장단, 시즌 기록·경력·수상 조회, 은퇴, 유스 인테이크와 게임 중 선수 생성.

**훈련도 여기다** — 기본 훈련 배치, 훈련 지시(팀 세션·개인 훈련·개인 휴식·집중 육성), 훈련
결산의 브리프와 사실 카드, 2군 월간 성장 배율. 결산을 장부에 반영하고 보고 메일을 보내는 흐름은
`app/workflows/training-report.ts`가 엮는다.
