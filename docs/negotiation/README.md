# 협상과 구단 운영

선수의 이적·재계약·임대·해지를 논의하고 결정한다. 대면·통화·제안서를
협상 GM이 같은 상대의 협상 테이블에서 진행하고, Jev가 맥락에 맞는 조건과 후속 일정을 평가한다.
코어는 계약·소속·지급·약속을 검증해 확정한다.

- [선수 거래와 협상](transfer.md): 경험 흐름, GM별 스킬, 조건 평가, 연락 기록, 후속 이벤트.
- [스카우팅](scouting.md): 메인 GM 의뢰, Jev의 조사 계획·예상 정보 수준, 예정일 이벤트와 보고서.

- [재정](finance.md): 현금·예산·급여·분할 지급과 계약 확정의 실행 가능성.
- [인물과 기억](../story/people.md): 협상 과정과 결과가 일상·관계·회견으로 이어지는 방식.

선수·구단·인물은 common의 같은 ID를 참조한다. 거래 기록은 negotiation이 소유하고,
app이 시간 진행·협상 GM·메인 GM을 연결한다. 화면에서 나가는 것과 거래를 철회하는
것은 다르며, 같은 상대에게 돌아오면 이전 연락과 약속이 이어진다.

코드는 `packages/{domain,engine,agents}/src/negotiation`과
`apps/web/domains/negotiation`, 교차 도메인 실행은 `app/workflows/negotiation`에 둔다.
스카우팅은 이 도메인의 독립된 조사 흐름이다. 메인 GM이 의뢰하고 Jev가 계획과 보고를 평가한다.
협상 GM은 실제 상대와 연락할 때 참여한다. 감독·스태프 계약도 선수 거래 판정과 구분한다.
