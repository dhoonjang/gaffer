# Gaffer 초대 베타 배포 설계

**초기 동시 접속 10명 이하, 무료 인프라 우선.** 실행 코드·배포·계정 생성·커밋은 이번 작업에 포함하지 않는다. 이 폴더는 미구현 제안이며 현재 서비스 동작을 설명하는 `docs/`와 구분한다.

## 읽는 순서

1. [전체 인프라 설명](infrastructure-overview.md): React/Nest 역할과 작업 실행기가 필요한 이유, 한 턴의 흐름.
2. [최종 설계](final-design.md): 전체 구성, 인증, 저장·작업 계약, 피드백·데이터, 비용, 백업, 구현 순서와 출시 검증.
3. [교차 검토 합성 결과](review-results.md): 쟁점별 채택·기각과 근거.
4. [검토 근거](evidence.md): 현재 코드와 합성 측정, 역사적 개발 로그의 범위와 한계.
5. [공통 입력](input.md): 원래 요청과 이후 10명 이하·무료 우선 조건.
6. 독립안과 교차 검토: [Codex 독립안](codex-design.md), [Claude 독립안](claude-design.md), [Codex의 검토](codex-review.md), [Claude의 검토](claude-review.md).

## 권장 구성

| 책임                    | 선택                                                                      |
| ----------------------- | ------------------------------------------------------------------------- |
| 화면·API                | React/Vite는 Cloudflare Pages, Nest API는 Cloud Run 최소 0                |
| 턴·경기 검증            | 긴 작업은 Cloud Tasks, 짧은 명령·경기 검증은 같은 저장 계약으로 즉시 실행 |
| 초대·로그인             | Supabase Free Auth + 서버의 초대·membership 검사                          |
| 소유권·작업·비용·피드백 | Supabase Free PostgreSQL                                                  |
| 큰 세이브·백업          | R2 private 객체 + DB의 원자적인 참조 전환, 독립 GCS 백업                  |
| 로그·오류·제품 분석     | Cloud Logging, Sentry Free, PostHog 무료 제공량                           |
| 복구                    | 매일 DB + 객체 백업, 중복/중단 작업은 lease와 receipt로 복구              |

가벼운 사용에서 인프라 월 **약 $0–10**, 사용량이 크거나 실행이 길면 **$10–30+**를 예산 범위로 본다. 완전 무료 보장은 아니며 **LLM API는 별도**다. 세부 가정·공식 요금 링크는 최종 설계 §13을 따른다.

React 화면과 Nest API를 분리한다. 서버의 공통 저장·작업 계약은 프레임워크에 의존하지 않고, LLM·경기 검증은 같은 백엔드 이미지의 별도 실행 역할로 배포한다. 기존 교차 검토는 저장·작업·복구 계약과 Next 기반 배포안을 대상으로 했으며, React/Nest와 프론트 프록시 전환은 후속 대화의 제안이다. 해당 연결 경로는 구현 시 별도 통합 검증한다.

무료안은 콜드 스타트와 DB 휴면 가능성을 받아들인다. DB를 잃으면 일일 백업 이후 최대 하루의 진행이 사라질 수 있다. 이 한도가 맞지 않거나 무료 제공량의 80%에 지속 접근하면 유료 DB/백업부터 전환한다.

## 구현 시작점

React/Vite 화면과 Nest API 경계, 같은 origin의 API 전달 및 로그인부터 정비한 뒤 아래 계약을 구현한다.

1. 비동기 저장 repository, 소유권, 초대와 인증.
2. 영구 job·중복 방지·lease/fence·Cloud Tasks 전달과 복구.
3. 화면의 작업 상태·증분 응답·다중 기기 경기 제어.
4. 호출별 비용 예약·사용량, 피드백과 운영 관측.
5. 배포 자동화와 실제 백업 복원 후 2 → 5 → 10명 초대.

수백 명 대응은 같은 계약 위에서 worker·DB·모델 제공자 quota를 확장하는 다음 단계다. 초기에는 해당 규모의 상주 비용을 내지 않는다.
